#### Music & audio

- [Camel](https://github.com/lucidbeaming/Camel): Arduino + Mozzi sketch for a keyless drone synthesizer
- [vid2midi](https://github.com/lucidbeaming/vid2midi): generate MIDI files from brightness levels in video
- [Fluidsynth-Webapp](https://github.com/lucidbeaming/Fluidsynth-Webapp): Node web app for controlling FluidSynth over its telnet shell
- [ZynAddSubFX-WebApp](https://github.com/lucidbeaming/ZynAddSubFX-WebApp): mobile web UI for switching ZynAddSubFX instruments on a Raspberry Pi via OSC
- [pi-synths](https://github.com/lucidbeaming/pi-synths): scripts for building music machines on Raspberry Pi

#### Media tools

- [mutant](https://github.com/lucidbeaming/mutant): desktop batch media converter built on ffmpeg and ImageMagick
- [ffmpeg-utilities](https://github.com/lucidbeaming/ffmpeg-utilities): real-world ffmpeg commands for video, image and audio work, commented, tested and grouped by theme
- [channelswap](https://github.com/lucidbeaming/channelswap): color-swapped images from RGB channels recombined across images
- [audio-screenshotter](https://github.com/lucidbeaming/audio-screenshotter): record screen + mic narration, then extract screenshots aligned to a transcript
